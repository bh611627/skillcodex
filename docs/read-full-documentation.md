# Read full documentation before acting

Skills are **short policies**, but they link to longer `references/*.md` files. Hosts may show excerpts; **implementors should still load the full sources**.

## Rules for anyone applying a skill

1. Open the skill’s **`SKILL.md` from top to bottom** — frontmatter sets risk, tools, and outcomes.
2. Open **every `references/` path** listed in frontmatter before editing code or giving SEO advice.
3. Prefer the **raw GitHub URL** when the file is missing locally:

   `https://raw.githubusercontent.com/bh611627/skillcodex/main/references/google-seo.md`

4. If the user’s task spans two skills (e.g. SEO + doc UI), read **both** full files before merging guidance.

## Why this exists

Partial reads cause contradictory motion tiers, wrong Next.js router APIs, or SEO checklists that skip Search Console field data. Full reads keep behavior aligned with SkillCodex maintenance.
