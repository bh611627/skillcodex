# Repository layout

SkillCodex is a **skills-first** repo: human-readable `SKILL.md` trees, supporting references, and an optional **npm** mirror under `package/`.

```
Skills-Agent/                    # clone of github.com/bh611627/skillcodex
├── skills/                      # Source of truth: one folder per skill
│   └── <skill-name>/
│       └── SKILL.md
├── skills-sh-catalog/           # Generated mirror: skills/<name>/SKILL.md (pnpm export-skills-sh)
│   ├── README.md
│   ├── REQUIREMENTS.md          # skills.sh docs alignment checklist
│   └── skills/
│       └── <skill-name>/
│           └── SKILL.md         # copy of ../skills/<name>/SKILL.md
├── references/                  # Shared deep rules (linked from skills, keeps SKILL.md slim)
├── package/                     # @skillcodex/skills - sync + publish only
│   ├── src/skills/              # Generated from ../skills/*/SKILL.md (do not hand-edit)
│   ├── scripts/
│   │   ├── sync-from-skills.mjs
│   │   └── validate-skills.mjs
│   └── package.json
├── contrib/                     # Optional bundles for upstream PRs (e.g. vercel-labs/skills)
├── examples/                    # Placeholder for future sample apps (optional)
├── README.md                    # Entry + links
├── DIRECTORY.md                 # skills.sh-style table
├── SKILL_STANDARD.md            # YAML + section contract for skills
├── GIT_WORKFLOW.md              # Branches, commit hygiene, npm release
├── SECURITY.md / TRUST.md       # Hygiene and threat model
└── REPO_LAYOUT.md               # This file
```

## Where to edit

| Goal | Edit |
|------|--------|
| Skill behavior / outcomes | `skills/<name>/SKILL.md` |
| skills.sh–shaped mirror | Run `pnpm export-skills-sh` (writes `skills-sh-catalog/skills/`) |
| Long UI rules | `references/design-guidelines.md` (and link from skill) |
| npm module text / exports | Run `pnpm run sync` in `package/` after SKILL changes |
| Vercel CLI repo PR | `contrib/vercel-labs-skills/` → copy into a **fork** of `vercel-labs/skills` |

## What not to hand-edit

- **`package/src/skills/*.ts`** - regenerated by `pnpm run sync` from `skills/*/SKILL.md`.
- **`package/dist/`** - build output; gitignored; produced by `pnpm run build`.

## Git status symbols (common shells)

| Symbol | Meaning |
|--------|---------|
| `main` | Current branch |
| `+N` | **N** staged files |
| `!N` | **N** modified but **not** staged |
| `?N` | **N** untracked files |
| `MM` | File has both staged and unstaged changes (clean up with `git add` or `git restore`) |

You are in the right directory if `pwd` ends in `Skills-Agent` (or your clone name) and `git remote -v` points at **skillcodex**.
