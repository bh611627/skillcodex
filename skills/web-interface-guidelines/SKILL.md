# Instructions

Audit UI per Web Interface Guidelines. Design rules: [DESIGNSPEC.md](../../references/DESIGNSPEC.md).

Cover: labels, focus-visible, semantic HTML, reduced motion, no `transition: all`, next/link, next/image dimensions, aria-live for toasts.

Icon buttons: react-icons + aria-label ([icons-and-emoji.md](../../references/icons-and-emoji.md)).
